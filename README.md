# **Elite Dangerous High-Performance Router**

This project provides a web-based routing tool for Elite Dangerous that uses a highly-optimized C++ backend for A\* pathfinding on a complete EDSM star map.  
**Core Features:**

* **Optimized In-Memory Cache:** On startup, the application loads a pre-computed binary cache (starmap.cache) directly into RAM. This reduces startup time from minutes to seconds.  
* \**Bi-directional A* Search:\*\* The C++ engine simultaneously searches from the start and end points, dramatically reducing the search space and calculation time.  
* **Multi-threaded & Mutex-Free:** The most expensive part of the search (neighbor expansion) is parallelized across all available CPU cores using a high-performance thread pool with minimal lock contention.

## **Project Structure**

* index.html: The frontend user interface.  
* app.py: The Python Flask backend.  
* setup.py: The build script for the C++ Python module.  
* astar\_search.cpp: The high-performance C++ A\* search engine.  
* generate\_cache.cpp: A utility to create the binary cache.  
* import\_starmap.go: A Go script to import the EDSM data into a database.  
* starmap.db: The SQLite database (generated by the Go script).  
* starmap.cache: The binary cache for fast startups (generated by generate\_cache).

## **Build & Run Instructions**

This guide provides a complete walkthrough from a clean environment to a running application.

### **For Windows Users**

These steps should all be performed within the **"x64 Native Tools Command Prompt for VS 2022"**.

#### **Step 1: Install Prerequisites**

1. **Python:** Install a **64-bit** version of [Python 3.10+](https://www.python.org/downloads/).  
2. **Go:** Install [Go 1.18+](https://go.dev/dl/).  
3. **Visual Studio Build Tools:** Download "Build Tools for Visual Studio" from the [Visual Studio website](https://visualstudio.microsoft.com/downloads/). During installation, select the **"Desktop development with C++"** workload.

#### **Step 2: Prepare C++ Libraries**

1. **SQLite:**  
   * Go to the [SQLite Download Page](https://www.sqlite.org/download.html).  
   * Download the **"sqlite-amalgamation-....zip"** file.  
   * Create a folder C:\\sqlite.  
   * Extract sqlite3.h and sqlite3.c into C:\\sqlite.  
2. **Boost:**  
   * Go to the [Boost website](https://www.boost.org/users/download/) and download the latest version.  
   * Extract the contents to a folder, e.g., C:\\boost\\boost\_1\_89\_0.  
   * **Build the Boost libraries:**  
     * Open the **"x64 Native Tools Command Prompt for VS 2022"** (search for it in your Start Menu).  
     * Navigate to your Boost directory: cd C:\\boost\\boost\_1\_89\_0  
     * Run .\\bootstrap.bat  
     * Run the following command to build the necessary 64-bit libraries. This may take several minutes.  
       .\\b2.exe address-model=64 link=static,shared runtime-link=static,shared \--with-serialization

#### **Step 3: Set Up the Project Environment**

1. **Clone or download** this project's source code into a folder, for example C:\\git\\edrouter.  
2. Open the **"x64 Native Tools Command Prompt for VS 2022"**.  
3. Navigate to the project directory: cd C:\\git\\edrouter  
4. **Set Environment Variables** for your current terminal session:  
   set BOOST\_ROOT=C:\\boost\\boost\_1\_89\_0  
   set SQLITE\_ROOT=C:\\sqlite

5. **Verify the x64 environment**. Run cl /? | find "x64". The output must include a line with "x64". If it mentions "x86", you are in the wrong command prompt.

#### **Step 4: Build the Data Pipeline**

1. **Download EDSM Data:** Download the systemsWithBodies.json.gz file from the [EDSM Dumps page](https://www.google.com/search?q=https://www.edsm.net/en/dumps) and place it in your project root (C:\\git\\edrouter).  
2. **Install Go Dependencies:**  
   go get \[github.com/mattn/go-sqlite3\](https://github.com/mattn/go-sqlite3)

3. **Create the SQLite Database:** This is a one-time step that parses the EDSM dump. It will take a long time.  
   go run \-tags "sqlite\_fts5 sqlite\_rtree" import\_starmap.go

4. **Create the Binary Cache:** This is a one-time step that creates starmap.cache for fast startups.  
   * First, compile the utility:  
     cl /EHsc /O2 /std:c++17 /I"%BOOST\_ROOT%" /I"%SQLITE\_ROOT%" generate\_cache.cpp "%SQLITE\_ROOT%\\sqlite3.c" /Fe:generate\_cache.exe /link /machine:x64 /LIBPATH:"%BOOST\_ROOT%\\stage\\lib"

   * Then, run it:  
     .\\generate\_cache.exe

#### **Step 5: Build and Run the Application**

1. **Install Python Dependencies:**  
   pip install Flask Flask-Cors pybind11

2. **Compile the C++ Module:**  
   python setup.py build\_ext \--inplace

3. **Run the Server:**  
   python app.py

4. Open your web browser and navigate to http://127.0.0.1:5000.

### **For macOS & Linux Users**

#### **Step 1: Install Prerequisites**

Use your system's package manager to install the necessary tools.  
\# Ubuntu / Debian  
sudo apt-get update  
sudo apt-get install python3-pip python3-venv go-lang build-essential libsqlite3-dev libboost-dev

\# macOS (with Homebrew)  
brew install python go sqlite boost

#### **Step 2: Set Up the Project Environment**

1. **Clone or download** this project's source code.  
2. Open a terminal and cd into the project directory.  
3. Create and activate a Python virtual environment (optional but recommended):  
   python3 \-m venv venv  
   source venv/bin/activate

#### **Step 3: Build the Data Pipeline**

1. **Download EDSM Data:** Download systemsWithBodies.json.gz from the [EDSM Dumps page](https://www.google.com/search?q=https://www.edsm.net/en/dumps) and place it in the project root.  
2. **Install Go Dependencies:**  
   go get \[github.com/mattn/go-sqlite3\](https://github.com/mattn/go-sqlite3)

3. **Create the SQLite Database:** This is a one-time step that will take a long time.  
   go run \-tags "sqlite\_fts5 sqlite\_rtree" import\_starmap.go

4. **Create the Binary Cache:** This is a one-time step.  
   * First, compile the utility:  
     g++ \-std=c++17 \-O3 \-o generate\_cache generate\_cache.cpp sqlite3.c \-lsqlite3 \-lboost\_serialization

   * Then, run it:  
     ./generate\_cache

#### **Step 4: Build and Run the Application**

1. **Install Python Dependencies:**  
   pip install Flask Flask-Cors pybind11

2. **Compile the C++ Module:**  
   python setup.py build\_ext \--inplace

3. **Run the Server:**  
   python app.py

4. Open your web browser and navigate to http://127.0.0.1:5000.
